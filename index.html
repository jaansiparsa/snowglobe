Snowcase

Turn any photo, sketch, or Gaussian-splat capture into a glass snow globe you can shake. Snowcase renders it in the browser in real time. The technical work is glass refraction, snow particle physics, and swirling water.

05 Resources

References, platform & starting point

References

  • Pharr, Jakob & Humphreys, Physically Based Rendering. Refraction, Fresnel, transmission. pbr-book.org
  • Bridson et al., “Curl-Noise for Procedural Fluid Flow,” SIGGRAPH 2007. Divergence-free swirling fields.
  • Stam, “Stable Fluids,” SIGGRAPH 1999. Real-time fluid solver for the stretch goal.
  • Kerbl et al., “3D Gaussian Splatting for Real-Time Radiance Field Rendering,” SIGGRAPH 2023. project page
  • Three.js documentation. Transmission material, GPU particles, environment maps. threejs.org/docs

Platform, hardware & software

  • Platform: the web. WebGL2 via Three.js with GLSL shaders. Runs in desktop and mobile browsers.
  • Hardware: personal laptops (macOS) for development, a phone for the device-motion shake.
  • Software: JavaScript / TypeScript, Three.js, Vite, Git / GitHub.

Starting point

We start from the open-source Three.js library and its transmission-material and GPU-particle examples, adapting them rather than using them as-is. Our work lives in the project repository: github.com/jaansiparsa/snowglobe.
