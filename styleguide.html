A Color tokens

Palette

Defined as CSS variables on :root and auto-inverted in dark mode. Reference them as var(--ink) etc. — don't hard-code hex values.

--bg
--ink
--muted
--faint
--line

B Headings

Type scale

Section number + name uses .sec-label; the big serif heading is <h2>; sub-headings are <h3>.

01 Section name

Serif section heading

Uppercase sub-heading

<p class="sec-label"><b>01</b> Section name</p>
<h2>Serif section heading</h2>
<h3>Uppercase sub-heading</h3>

D Lists

Bulleted list

Plain <ul> / <li> — the hairline tick mark is added automatically.

  • First item.
  • Second item, a little longer so you can see how it wraps onto a second line.
<ul>
  <li>First item.</li>
  <li>Second item.</li>
</ul>

F Two-column split

Side-by-side columns

Used for the required plan-vs-hope deliverables. Collapses to one column on phones. The italic .n span is an optional numeral.

i. Left column

  • Point one.
  • Point two.

ii. Right column

  • Point one.
  • Point two.
<div class="split">
  <div>
    <h3><span class="n">i.</span> Left column</h3>
    <ul><li>Point one.</li></ul>
  </div>
  <div>
    <h3><span class="n">ii.</span> Right column</h3>
    <ul><li>Point one.</li></ul>
  </div>
</div>
